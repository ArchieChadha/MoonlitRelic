Moonlit Relic - 3D Adventure Game

Moonlit Relic is an immersive 3D adventure game set in a mystical world where players journey through rich, hand-crafted environments to uncover hidden relics and secrets. The game features a combination of puzzle-solving, exploration, and adventure elements, designed to engage players in a captivating narrative and visually stunning gameplay.

Technologies Used
1. Game Engine: Unity 3D – Used for creating and managing the entire game environment, including physics, animations, and game logic.
2. Visual Studio Code: C# was used for scripting game mechanics, interactions, and user interface logic, enabling fluid and responsive gameplay.
3. Graphics: Blender – Custom 3D models, environments, and textures were created for a unique art style. Unity Asset Store assets were also used for supplementary elements.
4. Audio: Unity’s built-in audio tools – Utilized for implementing sound effects, background music, and other in-game audio elements.
5. Game Physics: Unity’s built-in physics engine – Used to create realistic interactions and movements within the game environment.
6. Animation: Unity Animator – Created custom animations for characters, objects, and environmental elements to enhance realism and gameplay.
7. Version Control: Git/GitHub – Used for version control to manage updates, track changes, and collaborate on the project.

Key Features
1. Expansive 3D Environments: Explore a variety of beautifully designed landscapes, from lush forests to ancient ruins, each filled with hidden secrets and relics to discover.
2. Custom 3D Models: Every in-game object, character, and environmental texture was meticulously created using Blender to give the game a unique, visually rich style.
3. Puzzle and Exploration Elements: Engage with interactive puzzles that challenge the player’s intellect and curiosity. Solve riddles, unlock new areas, and progress through the game world.
4. Seamless Gameplay: Developed with a focus on smooth mechanics and immersive controls, ensuring players can fully experience the adventure without interruption.

Gameplay Overview
In Moonlit Relic, players are tasked with uncovering the ancient relic hidden deep within the forgotten world. The journey is filled with puzzles that require both critical thinking and exploration. Along the way, players will encounter various obstacles, enemies, and NPCs that offer clues to guide them on their quest. With each step, the narrative unfolds, revealing the deeper mysteries of the game world.

Installation Instructions
Clone or download this repository to your local machine.
git clone https://github.com/ArchieChadha/MoonlitRelic.git
Open the project in Unity.
Press the Play button in Unity to start playing the game directly within the editor.
Optionally, you can build the game to run on your local machine or any supported platform.
